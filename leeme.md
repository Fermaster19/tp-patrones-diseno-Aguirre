TP Patrones de Diseño Aguirre Claudio

Desafío 1 - Singleton
Se aplicó Singleton para evitar múltiples instancias de configuración.
Mejora: reduce uso de memoria y mantiene consistencia global.

Desafío 2 - Decorator
Se aplicó Decorator para agregar ingredientes dinámicamente.
Mejora: evita crear muchas clases.

Desafío 3 - Adapter
Se aplicó Adapter para adaptar un sistema nuevo sin modificar código existente.
Mejora: desacopla sistemas incompatibles.

Desafío 4 - Mediator
Se aplicó Mediator para centralizar la comunicación entre usuarios.
Mejora: reduce dependencias entre objetos.

Desafío 5 - MVC
Se separó en Modelo, Servicio y Vista.
Mejora: código más organizado y mantenible.
